# Flywise Website

Static website for Flywise International Private Limited. The site is intentionally kept as plain HTML, CSS, JavaScript, and image assets so edits remain easy to review and deploy.

## Project structure

- `home.html` — primary landing page.
- `about.html` — company, office, vision, and team information.
- `contact.html` — contact details, enquiry form, map, and quick-contact links.
- `privacy.html` and `terms.html` — legal pages.
- `css/style.css` — shared visual system, page sections, responsive rules, and shared components.
- `css/contact.css` — contact-page-specific styles.
- `js/main.js` — shared navigation, header state, slider, FAQ, reveal, statistics, and footer-year behaviour. Features safely check whether their matching element exists.
- `images/` — locally supplied brand and page imagery.

## Editing guide

- Update navigation and shared footer markup in each page; this is static HTML and is deliberately not generated by JavaScript.
- Update contact numbers, WhatsApp links, and address only after confirmation from Flywise.
- Update a page's title and meta description in that page's `<head>`.
- Update landing-page section content in `home.html`; update page-specific content in the respective page file.
- Add a new page at the project root, load `css/style.css` and `js/main.js`, then add its navigation/footer links deliberately.
- Put shared styling in `css/style.css`; add a page stylesheet only when a page has a substantial independent style block.

## Important client values

Treat the company name, telephone numbers, WhatsApp number, address, Google Maps coordinates, existing URLs, fees, programme details, legal text, and SEO wording as approved business data. Do not change them without client confirmation.
